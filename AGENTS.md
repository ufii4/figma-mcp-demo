# Task: UI Components Library with Theme System

## Goal

Build a production-quality web UI component library inside this Astro project. The library must include a live catalog page that displays all component variants and supports runtime theme customization.

## Stack

- **Base:** Astro 5 (already configured)
- **Frameworks:** Unrestricted, use any component library as you wish. 

### Requirements

1. **Color scheme toggle** — light / dark mode switch that applies globally
2. **Color theme selection** — at least 4 named palettes that swap primary, secondary, accent, and surface colors
3. **Font style selection** — at least 3 font presets that change the base font family

## Components

Pick up 3-5 common web components to display in the library. 

## Pages

Unrestricted, you can create a landing menu that leads to your components, simple catalog that show your components, or any UI design you want to make. 

## Quality Standards

1. user needs to access scheme, theme and font settings, adjusting the settings should update your components simultaneously.
2. components should have variants
3. use playwright-cli to visual test your implementation for better quality
